## <img src="https://vicons-svg-api.veasnawt.workers.dev/idea.svg?color=FFD166&size=28&stroke=1.7" width="22" height="22" alt="Idea icon" /> Why I Build

- **Make Khmer typing easier to learn.** Language tools should respect Khmer writing and keyboard layouts rather than treat them as an afterthought.
- **Learn by building real things.** Each project gives me a reason to study programming, design, architecture, debugging, testing, and performance.
- **Keep useful software accessible.** I prefer lightweight projects that avoid unnecessary paywalls, forced accounts, and recurring server costs whenever possible.
- **Use AI without losing independence.** AI can help me move faster, but understanding the system is still my responsibility.
